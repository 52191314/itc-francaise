# ITC Francaise (Web App)

A web port of the offline French A1–B1 dictionary and interactive reading application with identical UI and UX to the mobile app.

## Features
- **Dictionary Search:** Fast search across French vocabulary with English glosses and CEFR level tags (A1/A2/B1).
- **Interactive Paragraphs:** Reading passages with tap-to-inspect word definitions.
- **Flashcards & Quizzes:** Vocabulary study and review modes.
- **Audio Pronunciation:** Web Speech API integration for natural French pronunciation.
- **Responsive Layout:** Adaptive Flutter CanvasKit rendering for desktop, tablet, and mobile browsers.

## Deployment on Vercel
Configured for zero-config SPA hosting via `vercel.json`.

```bash
# To rebuild web bundle from Flutter source:
rebuild_web.cmd
```
